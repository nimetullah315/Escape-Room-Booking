# Escape Room Booking

## Description

API-et skal gjøre det mulig å administrere escape rooms og bookinger.

## Teknologi

### Prosjektet skal bruke:

1. Node.js
2. Express
3. JavaScript
4. Sequelize
5. Microsoft SQL Server

## Installation

1. Clone the repository
2. Run `npm install`
3. Start the server with `npm start`

## Usage

Visit `http://localhost:3500/api/bookings` in your browser to use the application or Use _postman_ to ckeck some specific features like **get, delete, post or update** booking.

1. GET /api/bookings
2. GET /api/bookings/:id
3. POST /api/bookings
4. DELETE /api/bookings/:id

Visit `http://localhost:3500/api/rooms` in your browser to use the application or Use _postman_ to ckeck some specific features like **get, delete, post or update** escaperoom.

1. GET /api/rooms
2. GET /api/rooms/:id
3. POST /api/rooms
4. PUT /api/rooms/:id
5. DELETE /api/rooms/:id
